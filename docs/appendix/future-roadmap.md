# Future Roadmap (Directional)

The milestones below summarize the internal narrative arc captured in `internal-docs/01_Vision`. They are directional and subject to change—use them as context, not as a public commitment.

## Horizon 1 — Now (H1)

- Safe, delegated swaps on Monad testnet via the CLI and web app.  
- Intent → policy → simulation → execution pipeline with human-readable receipts.  
- Minimal surfaces (CLI + lightweight UI) to keep reliability high.

## Horizon 2 — Next

- Extend the intent engine beyond swaps: bridging, NFTs, portfolio moves, recurring automations.  
- Strengthen the policy layer with richer allow/deny lists, risk signals, and simpler rotation UX.  
- Broaden wallet/paymaster integrations (EIP‑7702 stateless delegations, alternate paymasters).  
- Introduce pluggable “skills” so new actions can be added without restructuring the core engine.

## Horizon 3 — Platform

- Ship an SDK/agent platform that third parties can embed.  
- Improve delegation ergonomics (scoped permissions, intuitive revoke-all, safer defaults).  
- Add verifiable proofs/attestations around pre- and post-trade checks.

## Horizon 4 — s0nderlabs OCI

- Build towards chain- and mempool-aware on-chain intelligence with verifiable behavior.  
- Blend off-chain computation with proofs where it matters.  
- Deliver a natural-language interface that makes blockchain feel intuitive by default.

As H1 evolves, revisit this roadmap to align user-facing docs with current behavior. Longer-term goals should be communicated externally only when product plans solidify.
