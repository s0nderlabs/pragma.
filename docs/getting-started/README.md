# Getting Started

Welcome to Pragma! This section will help you get up and running in just a few minutes.

## Before You Begin

You'll need:
- A web browser (Chrome, Firefox, Safari, or Edge)
- A Google account or email address for sign-in
- Some MON tokens for transactions (you can get these from an exchange or bridge)

## The Basics

### 1. Connect Your Wallet
Sign in with Google or email. Pragma creates a smart account for you automatically.

### 2. Get Some MON
Transfer MON to your smart account address. You'll see this address in the sidebar after connecting.

### 3. Start Chatting
Type what you want to do in plain English. For example:
- "What's my balance?"
- "Swap 1 MON to USDC"
- "Stake 10 MON"

### 4. Confirm Transactions
Review the details and confirm. In Quick Mode, transactions execute immediately without confirmation.

## Your First Actions

Here are some things to try:

```
"Show my balances"
```
See all your tokens and their USD values.

```
"Swap 0.1 MON to USDC"
```

