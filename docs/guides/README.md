## Before You Start

Make sure you have:
- Connected your wallet via Web3Auth
- Some MON in your smart account
- Basic understanding of [Core Concepts](../concepts/README.md)

## Guide Format

Each guide includes:
- **Prerequisites**: What you need before starting
- **Steps**: Detailed instructions with expected outputs
- **Tips**: Best practices and common mistakes
- **Troubleshooting**: Solutions for common issues
