## Adding New Tokens

New tokens are added based on:
- Liquidity availability
- Protocol partnerships
- Community demand

Check periodically for updates to the token list.

## Token Standards

All tokens on Pragma are:
- **ERC-20 compliant**
- **Verified contracts**
- **Listed on Monorail DEX**

## Price Information

Pragma shows USD values alongside token amounts:

```
You have 5.0 MON (~$17.50)
```

Prices are fetched in real-time from DEX liquidity pools.

## Minimum Amounts

| Token | Minimum Swap |
|-------|-------------|
| MON | 0.01 MON |
| USDC | 0.01 USDC |
| Others | Varies |

Very small amounts may fail due to dust limits.

## Notes

- Token list is curated for security
- Only tokens with sufficient liquidity are listed
- Testnet tokens have no real value
- Always verify token symbols before swapping
